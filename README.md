# DJIA Stock Market Analysis Dashboard

## About the Project
An interactive stock market analysis dashboard developed using Microsoft Power BI to analyze the performance of the Dow Jones Industrial Average (DJIA 30).

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Features
- Stock market performance analysis
- Open, High, Low and Close price analysis
- Daily and Year-over-Year returns
- 30-day and 90-day Moving Averages
- Cumulative returns
- Volatility analysis
- Return and Risk analysis
- Year-wise performance

## Project Files
- `.pbix` – Power BI dashboard
- `.pptx` – Project presentation
